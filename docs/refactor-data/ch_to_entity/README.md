# ClusterHandler-to-Entity Refactor Data

This directory stores frozen scaffolding artifacts used by the ClusterHandler removal migration.

These files were copied from `/private/tmp` and are treated as read-only migration inputs.

## Artifact checksum verification
Run:

```sh
python scripts/verify_refactor_artifacts.py
```

Expected SHA256 checksums are embedded in `scripts/verify_refactor_artifacts.py` and must match exactly.
